1. File cấu hình nginx.conf cho Angular (để fix lỗi F5 404):
Tạo file frontend/nginx.conf:
server {
    listen 80;
    server_name localhost;

    location / {
        root /usr/share/nginx/html;
        index index.html index.htm;
        try_files $uri $uri/ /index.html; # Không bao giờ bị 404 khi đổi route
    }
}
